# Dubbing Script — ဗီဒီယို ဒပ်လုပ်ကိရိယာ

Dubbing Script မှ ထုတ်ပေးသော JSON စာသားကို ဖတ်ပြီး၊ စာကြောင်းတစ်ကြောင်းချင်းစီ၏ အချိန်မှတ်တမ်းအတိုင်း အသံဖန်တီးကာ မူရင်းဗီဒီယိုနှင့် ပေါင်းစပ်ပေးသည့် Streamlit အက်ပ်ဖြစ်သည်။

## လုပ်ဆောင်ချက်များ

- JSON ဖိုင်နှင့် မူရင်းဗီဒီယိုကို တင်နိုင်သည်။
- JSON အတွင်းရှိ `segments`, `start`, `end`, `speaker_id`, `voice_type` နှင့် `text` တို့ကို စစ်ဆေးသည်။
- `speaker_id` တူညီသော စာကြောင်းများအတွက် တူညီသော အသံကို သုံးသည်။ အသံကို ဇာတ်ကောင်တစ်ဦးချင်း ရွေးချယ်နိုင်သည်။
- စကားပြောအသံများကို အချိန်မှတ်တမ်းအတိုင်း နေရာချထားပြီး အက်ပ်တွင် ရွေးထားသော အရေအတွက်အလိုက် တစ်ပြိုင်နက် ဖန်တီးသည်။
- မူရင်းဗီဒီယို၏ ရုပ်ပုံနှင့် အချိန်ကာလကို မပြောင်းပါ။ မူရင်းအသံကို အပြည့်အဝ ပိတ်ပြီး အသစ်ဖန်တီးထားသော စကားသံကိုသာ ထည့်သွင်းသည်။
- စကားပြောချိန်သည် သတ်မှတ်ထားသော အပိုင်းထက် ရှည်ပါက သတိပေးသည်။ စကားကို မဖြတ်ဘဲ နောက်စာကြောင်းနှင့် ထပ်နိုင်သည်။ ဗီဒီယိုအဆုံးထက် ကျော်လွန်သည့် အသံကို ဗီဒီယိုအဆုံးတွင် ဖြတ်တောက်မည်။

## လိုအပ်ချက်များ

- Python 3.8 နှင့်အထက်
- FFmpeg နှင့် FFprobe
- `requirements.txt` ထဲရှိ Python package များ

## စတင်အသုံးပြုခြင်း

```bash
pip install -r requirements.txt
streamlit run app.py
```

`ffmpeg` နှင့် `ffprobe` ကို စနစ်တွင် ထည့်သွင်းထားရမည်။

## အသုံးပြုပုံ

1. Dubbing Script မှ ထုတ်ထားသော `.json` ဖိုင်ကို တင်ပါ။
2. မူရင်းဗီဒီယိုကို တင်ပါ။ လက်ရှိတွင် MP4, MOV, AVI နှင့် MKV ကို လက်ခံသည်။
3. တစ်ပြိုင်နက် အသံဖန်တီးမည့် စာကြောင်းအရေအတွက်ကို ရွေးပါ။
4. ဇာတ်ကောင်တစ်ဦးချင်းအတွက် အသံကို ရွေးပါ။
5. ဒပ်လုပ်ဗီဒီယို ဖန်တီးပြီးနောက် ရလဒ်ကို ကြည့်ရှု၍ ဒေါင်းလုဒ်ရယူပါ။

## JSON နမူနာ

```json
{
  "version": 1,
  "language": "my-MM",
  "segments": [
    {
      "cue_id": "1",
      "start": "00:00:00,000",
      "end": "00:00:02,000",
      "speaker_id": "speaker_1",
      "age_group": "adult",
      "gender": "female",
      "voice_type": "adult_female",
      "text": "မင်္ဂလာပါ။"
    }
  ]
}
```

## အသံသုံးစွဲမှုဆိုင်ရာ မှတ်ချက်

လက်ရှိ Edge TTS တွင် မြန်မာအမျိုးသားအသံနှင့် မြန်မာအမျိုးသမီးအသံကို သုံးသည်။ ဇာတ်ကောင်ကို `kid_male` သို့မဟုတ် `kid_female` ဟု သတ်မှတ်ထားပါက သက်ဆိုင်ရာ အသံကို ရွေးပြီး အသံအမြင့်ပြောင်းပေးသည်။ ၎င်းသည် ကလေးအသံအစစ် မဟုတ်ပါ။

ဤဗားရှင်းသည် မူရင်းအသံလမ်းကြောင်းကို မထိန်းသိမ်းပါ။ ထို့ကြောင့် မူရင်းစကားသံသာမက နောက်ခံတေးသံနှင့် အသံအကျိုးသက်ရောက်မှုများလည်း မပါဝင်ပါ။
